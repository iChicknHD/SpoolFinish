# SpoolFinish

Plan a safe filament change at a completed layer boundary using the material left on your spool.

SpoolFinish is a free, local Windows utility for G-code generated by PrusaSlicer and OrcaSlicer. Enter the remaining filament weight, safety reserve, material, filament diameter, and firmware. SpoolFinish analyzes filament use, identifies the last complete layer that fits within the usable material, and shows where to change spools. When a change is needed, it can create a separate patched G-code file.

## Features

- Supports G-code from PrusaSlicer and OrcaSlicer
- PLA, PETG, ABS, and ASA material defaults
- 1.75 mm default filament diameter, with configurable diameter
- Configurable safety reserve
- Marlin `M600` and Klipper `PAUSE` pause commands
- Local processing, with no account, cloud upload, telemetry, or analytics
- The original G-code file is never overwritten

Firmware and printer compatibility depends on the target configuration.

2. Run `SpoolFinish.exe`.
3. Select a G-code file and enter the remaining filament and safety reserve.
4. Select **Analyze**.
5. Select **Create patched G-code** if a change is required.

The portable Windows build does not require a Python installation. The binary is currently unsigned, so Windows may show a reputation warning.

## Privacy

SpoolFinish works locally on your computer. The application does not use telemetry, analytics, cloud upload, accounts, or network communication. It reads the selected G-code file and writes any patched output as a separate file.

The public release ZIP was audited for secrets, local or private build paths, personal data, and unintended development artifacts. This is a release artifact review, not a formal security certification.

## Important limitations

SpoolFinish performs static G-code planning. Marlin `M600` requires compatible firmware configuration, such as `ADVANCED_PAUSE_FEATURE`. Klipper `PAUSE` requires compatible `pause_resume` configuration. Physical printer and firmware execution has not been validated across every printer. SpoolFinish fails closed when it cannot safely interpret G-code semantics.

## Validation

- Synthetic accounting and unit tests pass.
- OrcaSlicer 2.4.2 generated G-code was tested; its regression test passed.
- PrusaSlicer 2.9.6 generated G-code was tested. Filament-length analysis differed from the slicer's reported value by approximately 0.000205%.
- Patched output reparses successfully, and the source G-code remains unchanged.
- Physical printer runtime behavior is not covered by these tests.

## Development

Requires Python 3.12 or later.

```powershell
python -m pip install -e .
python -m spoolfinish.gui
```

CLI example:

```text
spoolfinish analyze print.gcode --remaining 83 --reserve 5 --material PLA --diameter 1.75 --firmware marlin
```
